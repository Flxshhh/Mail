# Hide Email — одноразовая почта

Сайт-приложение для iPhone: создаёшь одноразовый адрес, регистрируешься с ним где угодно,
а письмо с подтверждением появляется прямо в приложении. Ссылка подтверждения и код
вынесены отдельными кнопками.

**Адрес:** https://flxshhh.github.io/Mail/

## Как включить GitHub Pages
1. Репозиторий → **Settings → Pages**.
2. **Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
3. Через 1–2 минуты сайт откроется по адресу выше.

GitHub Pages на бесплатном аккаунте работает только для **публичных** репозиториев.

## На iPhone как приложение
Открой адрес в Safari → «Поделиться» → «На экран „Домой“».

## Как пользоваться
1. **«Создать почту»** — адрес создастся и сразу скопируется.
2. Укажи его при регистрации.
3. Вернись в приложение: почта проверяется каждые 5 секунд.
4. Открой письмо → «Ссылка подтверждения» или «Копировать» у кода.

Адрес всегда один. «Новая почта» заменяет его: старый адрес удаляется вместе с письмами,
но только после того, как новый успешно создан. Пока новый не создан, старый работает.

## Как устроено
Своего сервера нет. Почту принимает публичный сервис временной почты: сайт создаёт там ящик,
хранит доступ к нему в `localStorage` браузера и опрашивает API. Сервисы пробуются по очереди,
пока какой-нибудь не ответит: [mail.tm](https://mail.tm), mail.gw, [tempmail.lol](https://tempmail.lol),
[Guerrilla Mail](https://www.guerrillamail.com). У tempmail.lol ящик живёт около часа,
у Guerrilla Mail письма хранятся около часа. HTML письма показывается в `iframe` с `sandbox` без скриптов.

## Где хранятся данные
Адрес и письма хранятся **только в браузере этого устройства** (`localStorage`), синхронизации нет.
Если дать ссылку другу, у него будет свой адрес, а твоего он не увидит.

На iPhone у Safari и у иконки на экране «Домой» **разные хранилища**: адрес, созданный в Safari,
в приложении с иконки не появится. Пользуйся чем-то одним.

## Ограничения
- Пока приложение закрыто, уведомлений нет: для push на iOS нужен свой сервер.
- Некоторые сайты не принимают одноразовые домены — создай новый адрес или возьми другой сервис.
- Сервис хранит письма ограниченное время и может удалять старые ящики. Для важных аккаунтов
  одноразовая почта не подходит: восстановить пароль через неё не получится.

Локальный запуск: `python3 -m http.server` в папке проекта → `http://localhost:8000`.
